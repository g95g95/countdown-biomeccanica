# Countdown · Visita biomeccanica

Countdown a **venerdì 4 settembre 2026, ore 9:30 (ora italiana)** per la visita biomeccanica
da *Brian's il grande ciclismo*.

Pannello centrale con il conto alla rovescia (metà schermo) su sfondo a pioggia "Matrix":
le parole della frase *"Ore 9:30 visita biomeccanica Brian's il grande ciclismo"* scendono
in colonna, a volte nell'ordine giusto, a volte sciolte e slegate.

## Uso

È un singolo `index.html` senza dipendenze: aprilo nel browser oppure pubblicalo su GitHub Pages.

Per cambiare data/ora modifica `TARGET` in `index.html` (formato ISO con offset del fuso italiano:
`+02:00` con ora legale, `+01:00` con ora solare).
